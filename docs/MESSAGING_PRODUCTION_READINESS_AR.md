# جاهزية نظام الرسائل وSMS للإنتاج — CleanOps

**المشروع:** `nrc-aid` — **المستودع الوحيد:** `ayma7n982-del/CleanOps_Reports_Fixed_Download`.

## ما يعمل من داخل التطبيق

- مركز رسائل بأزرار واضحة للوارد والمرسل وغير المقروء والطوارئ وقيد المزامنة والفشل.
- فلاتر النوع والوجهة والفترة، والبحث العربي حتى مع اختلاف الهمزات أو ترتيب الكلمات.
- إنشاء رسالة داخلية، وتوجيه مباشر حسب الدور، وجدولة، وردود، ومرفقات صور وتأكيدات الاستلام.
- قائمة SMS خارجية مع سجل طلبات وأداة فحص حالة التسليم لدى المزوّد.
- شاشة «إعدادات SMS / API» تسمح لمدير المستوى الرابع (L4) بإدخال Account SID وAuth Token ورقم المرسل؛ المفاتيح لا تُحفظ في Firestore ولا على الهاتف.

## ما يجب التحقق منه قبل الإنتاج

1. من تبويب **Actions** في GitHub شغّل يدويًا **Messaging production deployment (manual and verified)** على الفرع `main`، مع اختيار `deploy=true`. لا تفعل ذلك قبل مراجعة الاختبارات.
2. في GitHub يجب أن تكون بيئة `firebase-production` وسر `FIREBASE_SERVICE_ACCOUNT` مهيئين وبتصاريح نشر Firebase الضرورية. يُفضّل تفعيل الموافقة اليدوية على البيئة.
3. يتطلب نشر Cloud Functions إمكانية الفوترة المسموح بها في Firebase وواجهات Google Cloud اللازمة، ولا يعني نجاح بناء APK أنها نُشرت.
4. في Google Cloud يجب تفعيل **Secret Manager API**. يمكن لمالك المشروع إنشاء الأسرار الثلاثة: `CLEANOPS_TWILIO_ACCOUNT_SID`, `CLEANOPS_TWILIO_AUTH_TOKEN`, `CLEANOPS_TWILIO_FROM` مرة واحدة. يمنح حساب الخدمة الذي يشغّل وظيفة Firebase صلاحيتَي **Secret Manager Secret Accessor** و**Secret Manager Secret Version Adder** على هذه الأسرار فقط. إذا كان التطبيق سيُنشئ الأسرار لأول مرة، يلزم مؤقتًا إذن الإنشاء من مسؤول Google Cloud.
5. افتح في التطبيق: **مركز الرسائل ← إعدادات SMS / API** بحساب L4. أدخل البيانات بنفسك في حقول الشاشة؛ لا تشارك مفاتيح API في الدردشة أو في لقطات الشاشة.
6. اختبر رقم مستلم مفعّلًا بصيغة دولية `+...` واستخدم زر تحديث الحالة في سجل SMS للتحقق من `delivered` أو `failed`. قبول المزوّد (`submitted`) ليس دليل تسليم.
7. جرّب التطبيق بحسابين فعليين على هاتفين، في وضع الاتصال ثم وضع عدم الاتصال والعودة إليه؛ راقب الرسالة المعلّقة، ثم إيصال القراءة وتأكيد الاستلام.
8. استخدم APK الناتج من **CleanOps Android APK** لأحدث Commit ناجح، وليس ملفًا من إصدار سابق.

**مهم:** الرسائل الداخلية لا تحتاج Twilio، أما SMS فقد تكون له تكلفة من مزوّد الخدمة. لا يُنشر Firebase ولا تُفترض صلاحيات مالك المشروع لمجرد إمكانية تحرير الكود في GitHub.
